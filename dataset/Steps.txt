* bisa jadi klasifikasi sudah ditemukan dari ICA filter (muscle movement)
* clean raw (data kosong, hilang, landai) --> ada hubungan dengan kualitas data (bisa jadi raw sudah clean raw)
 
3. Chunking : Data dibagi-bagi sesuai kesepakatan (karena sampling frequency 128 hz, maka chunk dibagi based on 2^x , bisa 2 detik juga digabung   )
* chunking ngaruh ke step 0

5. Encoding : encoding dari naik turun data, ketika data naik dinilai 1, ketika sama atau turun dinilai 0

* output data binary (sequential) --> yang mungkin akan difokuskan
